## Usage Guidelines

-   **Primary Blue (#0096DC)**: Main brand color for interactive elements
-   **Dark Blue (#002E44)**: Headers and primary text on light backgrounds
-   **Accent Blue (#0077B6)**: Hover states and secondary accents
-   **Light Gray (#FAFAFA)**: Background and light UI elements
-   **Dark Gray (#333333)**: Body text and secondary content

Please maintain proper contrast ratios and use these colors consistently across all ColDog Studios materials.
